# Supplementary material

[Read the supplementary PDF](cognitive_edge_supplement.pdf) · [Public-file inventory](../public_artifacts.json)

The PDF accompanies *Cognitive Edge Computing: A Survey on Optimizing Large Language Models and Autonomous Agents for the Edge*. It contains the extended evidence, deployment checks, source locators, and worked assistant contract referenced by the guide.

| Sections | Content |
|---|---|
| S1 | Historical server results, task definitions, descriptive variability, provenance, and transfer limits |
| S2–S4 | Extended applications, practitioner checklist, and computing-tier boundaries |
| S5–S7 | Frozen census, capability proxies, public artifacts, and reproduction guidance |
| S8–S9 | Survey editions, representative-study locators, and figure inputs |
| S10–S12 | Optimization and workflow reporting, model artifacts, and a prospective assistant contract |

The public repository distributes the rendered supplement PDF and supporting research artifacts. Editable submission sources and author-local TeX build files are not included. Reproduction notes for the released data and figures are in the [server archive](../server/README.md), [figure catalogue](../figures/README.md), and [protocol](../protocol.md).
